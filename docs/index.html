Overview

VN Translator is a web-based toolkit for translating visual novels and game projects across Ren’Py, RPG Maker MV/MZ, KiriKiri-KAG, Artemis, and general game-text workflows.

✅ Best practice: always translate from the real source files, keep a backup, and test inside the target engine after every export.

Choose a tool

  • Ren’Py Translator — translate a single .rpy file with engine-safe parsing.
  • Pro Ren’Py Translator — multi-file workflow with translation memory, bulk edit, undo/redo, and ZIP export.
  • RPG Maker Translator — translate one JSON at a time from data/*.json.
  • RPGM Ultimate — conversion-based workflow for larger RPG Maker batches.
  • KiriKiri-KAG Translator — translate .ks scenario files and overwrite extracted dialog directly back into the original script.
  • Artemis AST Translator — translate .ast/.asb scripts and overwrite extracted text directly back into the original script.
  • Game Text Editor — edit extracted lines from supported formats with backend parsing workflows.

What changed for KAG and Artemis

  • Their translators now follow the same engine-first approach as the Ren’Py and RPG Maker tools.
  • Both have dedicated dialog extractors and merge pages.
  • Both use upgraded parser logic derived from the Game Text Editor API workflow, but the web translators remain standalone tools.
  • No manual source-language field and no separate overwrite-slot step in the translator UI — the tool parses, translates, and writes back directly.

Typical workflow

  1. Back up your project folder.
  2. Get the correct source files for the engine you are translating.
  3. Pick a translation service and set a target language.
  4. Translate in small batches when the script is heavily tagged.
  5. Review the output in a preview or extractor/merge workflow.
  6. Replace files in the project and test in-game.
