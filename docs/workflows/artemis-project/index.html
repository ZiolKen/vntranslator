Translate an Artemis project

This workflow is optimized for readable Artemis projects where you have the original .ast / .asb files.

0) Start with clean source scripts

Before translating, confirm the files are readable text and the game already runs correctly with them.
Do not batch-edit unknown packed files.

1) Backup

  • Zip the whole script folder, or
  • initialize a git repo before any export or merge step

2) Translate safely

Option A: Direct translator flow

  1. Open Artemis AST Translator
  2. Translate one small .ast or .asb file first
  3. Export it and place it back into the project
  4. Launch the game and test the affected scene

Option B: Extractor review flow

  1. Open Artemis Dialog Extractor
  2. Review the extracted visible strings before translation
  3. Translate only after the parser output looks correct
  4. Merge the result back and compare the diff if needed

3) QA checklist

  • field names, commas, braces, arrays, and structural syntax remain valid
  • only visible strings were translated
  • names, choices, titles, and menu strings still render correctly
  • placeholders and escape sequences are unchanged

See: Formatting & placeholders

4) Test in-game

  • Test one translated file before large batches
  • Check route selections, menus, and title-like text
  • If a file fails to load, compare it with the original around the translated block
