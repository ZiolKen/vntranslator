Translate a KiriKiri-KAG project

  1. Extract or locate the real .ks scenario files.
  2. Back up the full scenario folder.
  3. Translate one small scenario file in KAG Translator.
  4. Test the output in-game.
  5. Batch-translate the rest of the project.

Manual workflow

When you want to translate outside the browser:

  1. Use KAG Dialog Extractor to export a JSON dialog pack.
  2. Translate the JSON lines in your preferred tool.
  3. Merge the translated JSON back with the original .ks script.

Important notes

  • KAG tags, labels, and control commands should not be translated.
  • Check output encoding carefully if the game expects Shift-JIS or UTF-16LE-based patch files.
  • Always test after replacing scripts.
