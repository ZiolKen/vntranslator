KiriKiri-KAG Translator

Use this tool to translate KiriKiri-KAG .ks scenario files while preserving commands, labels, inline tags, and visible text fields.

Open the tool: KiriKiri-KAG Translator

When to use it

  • You have one or more readable .ks files to translate now
  • You want a browser-based upload → translate → export workflow
  • You want direct overwrite back into the original file without source-language or overwrite-slot settings

Inputs

  • .ks files from the original project or a clean unpacked script folder
  • Common locations include scenario/, data/scenario/, and script/

Guide: How to get .ks files

Step-by-step

  1. Open KiriKiri-KAG Translator
  2. Select engine/model and paste your API key if required
  3. Choose the target language
  4. Upload one or more .ks files
  5. Translate a small file first
  6. Export and put the translated file back into the project
  7. Launch the game and test the scenes you changed

KAG formatting rules you must preserve

Commands and tags

  • @jump, @if, @call, @label
  • inline tags such as [r], [l], [p], [cm]
  • tag attributes, IDs, filenames, and other non-visible values

Visible text

Translate only dialogue, narration, names, and choice text that the parser extracts.

Escapes and punctuation

Preserve quotes, line breaks, spacing, and backslashes that affect parsing or message flow.

Dialog Extractor & QA

Use KAG Dialog Extractor when you want to inspect only extracted strings before translation or review a merge more carefully.

  • Check that commands still execute
  • Check names, menu choices, and message windows
  • Compare a few lines with the original if a scene looks wrong
