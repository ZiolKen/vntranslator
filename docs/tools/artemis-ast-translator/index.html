Artemis AST Translator

Use this tool to translate Artemis .ast and .asb script files while preserving keys, arrays, structural syntax, and other non-dialog data.

Open the tool: Artemis AST Translator

When to use it

  • You have readable Artemis script files and want direct overwrite back into the original file
  • You want a workflow similar to Ren’Py and RPG Maker: upload → translate → export → test
  • You want the same engine/model flow used by the current VN Translator stack

Inputs

  • .ast and .asb files from the real project script folder
  • Common locations include script/, scenario/, and data/script/

Guide: How to get .ast / .asb files

Step-by-step

  1. Open Artemis AST Translator
  2. Select engine/model and paste your API key if required
  3. Choose the target language
  4. Upload one or more .ast / .asb files
  5. Translate one small file first
  6. Export and place the translated file back into the project
  7. Run the game and inspect scenes, names, selections, and menus

Artemis formatting rules you must preserve

  • Do not translate field names, braces, commas, locale keys, internal IDs, or command syntax
  • Translate only extracted visible strings such as dialogue, names, titles, and choice text
  • Keep placeholders, escape sequences, and direct-overwrite mapping intact

Dialog Extractor & QA

Use Artemis Dialog Extractor if you want to audit extracted strings before translation or perform a manual merge review.

  • Test one file before batch translation
  • Check menus, route selections, and title-like text
  • Watch for broken commas, quotes, braces, or arrays if a file fails to load
