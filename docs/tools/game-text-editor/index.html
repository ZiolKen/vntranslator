Game Text Editor

Game Text Editor is the text-focused utility inside VN Translator. It uses backend parsing to load supported files into editable line lists.

Role in the toolkit

  • Good for quick edits, search/replace, cleanup, and backend-driven workflows.
  • Its API parser logic is also the basis for the upgraded KAG and Artemis extraction logic, but the KAG and Artemis translators remain separate standalone tools in the VN Translator UI.

Supported workflow types

  • Ren’Py
  • RPG Maker JSON
  • Tyrano / KAG
  • Artemis
